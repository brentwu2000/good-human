# Encounter System v0.2 — World-Space
Encounters are relationships between actors already present in Run World, not menu transitions.

Flow: discover pair → approach → dog provoke/bark → opponent reacts → humans engage in place → dog stays controllable → victory/defeat/disengagement → exploration continues immediately.

Before engagement, avoidance means maintaining distance/walking away. After engagement, moving the dog sufficiently far causes the human to attempt to break away and follow.

Avoid modal Fight/Run screens, BattleScene, arena teleport, scene reload, and freezing dog control.

Opponents: 3 ordinary pairs + Old Master. Old Master uses an unthreatening dog and ordinary/frail-looking older human whose strength is not revealed numerically.

Architecture must later support Bark, Leash Pull, dog positioning, nearby interactions and multiple active conflicts without introducing battle mode.
