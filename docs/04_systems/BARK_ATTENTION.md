# Bark / Attention Prototype

Bark is contextual communication/disruption.

## Prototype
A bark emits a world event with origin, direction/facing, intensity/type placeholder and source dog.

Nearby relevant actors evaluate reaction.

## Combat Candidate
Opponent human may briefly look/react if:
- dog is relevant/close enough;
- bark comes from useful direction;
- resistance/cooldown permits.

## Anti-Spam
Repeated barking should rapidly diminish effect in the same context.

## Future Hooks
friendly bark, warning, intimidation, owner command, dog-to-dog communication.

Sprint 04 implements only enough to validate combat agency.
