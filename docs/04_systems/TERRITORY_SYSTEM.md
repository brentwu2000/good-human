# Territory System v0.1
Territory represents scent, routine, rivals and repeated presence—not capture node + passive gold.

States: UNKNOWN / DISCOVERED / CONTESTED / CLAIMING / OWNED.
Data: id, name, owner_dog_id, claim_progress, claim_target, last_event, reward, related_goal_threads.

Mark Territory is a contextual Run World interaction. It can reveal ownership, provoke resident/rival, advance a claim after conditions, or create future defense/rematch threads.

First territory: Big Banyan Tree. Suggested claim rule: 3 successful relevant territory extractions.
Ownership changes local reactions/scent feedback, collection entry and grants one unique reward/event.
No Territory Battle Scene.
