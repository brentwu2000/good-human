# Dog Desire System v0.1
Layers: Primary Desire, Emergent Desire, Persistent Thread, Long-term Ambition.
Example: strange scent → half tennis ball → unfamiliar dog scent → find dog → discover banyan rival → lose → train human → return.
Data: id, category, dog_text, trigger conditions, completion conditions, persistence policy, next_desires, world_hint, reward/effect, priority.
Selection should consider unfinished threads, undiscovered nearby content, recent encounters, human growth, territory and collection gaps. Avoid repetition.
Primary reward is discovery/new possibility; loot/growth may supplement it.
