# Greed + Territory Systems v0.2

## Value Layers
SAFE: protected dog-backpack items.
UNBANKED: exposed run value.
PERMANENT: banked stash/progression.

When extraction becomes available, present current exposed value, owner condition, extraction direction and one meaningful temptation. World cues > dog cues > minimal HUD > text.

Temptations: rare scent/item, Banyan progress, rival/rematch, Dog Desire, special event, one-more-search.

Risk must be legible before commitment. Never silently scale enemies because the player stayed longer.

## Big Banyan
States: UNKNOWN → DISCOVERED → CONTESTED → CLAIMING → OWNED.

The dog first learns ownership through scent and rival behavior. MARK_TERRITORY is a contextual Run World interaction, never a capture circle. It may reveal owner/rival, update a Dog Desire, provoke a reaction and make the run eligible for claim progress.

Prototype claim target: 3 relevant successful extractions, data-driven. Merely touching/marking the point does not consolidate progress.

OWNED changes scent/local reactions/collection and unlocks one place-related reward/event. No passive income.

## Run Tension Director
Inputs: duration, unbanked value, owner condition, extraction distance, active desire, territory/rival state, special opportunity.
Outputs: ambient shift, fatigue, scent cue, rival presence, extraction cue, rare opportunity cue. Outputs are presentation, not arbitrary punishment.
