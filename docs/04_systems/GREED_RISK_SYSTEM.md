# Greed / Risk System v0.1
Three value layers:
SAFE — dog backpack/protected.
UNBANKED — human-carried run loot, lost on defeat.
PERMANENT — consolidated growth/home stash.

Risk comes from voluntary choice, not surprise punishment.
Temptations: rare scent/item, territory progress, rival/rematch, unresolved Dog Desire, special event, one-more-search.
After extraction becomes available, continuing becomes a real decision.
Record debug telemetry: run duration, first extraction opportunity, value then/at exit, opportunities pursued after extraction, defeat cause.
