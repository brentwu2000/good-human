# Sprint 05 — GREED / TERRITORY
Status: DESIGN STARTS NOW. ENGINEERING AFTER CORE EXPERIENCE GATE 02.

## Product Question
Can a walk create: “I already have enough to go home safely, but there is one more thing I really want?”

## P0
Run/unbanked value; temptation after extraction becomes available; one territory (Big Banyan Tree); Mark Territory; resident challenge; multi-run claim progress; unique reward; persistence; GOALS integration.

Loop:
discover banyan → smell rival → learn ownership → mark/challenge → seamless conflict → successful extract → claim progress → return/defend → ownership/reward.

Initial claim target: 3 relevant successful extractions, data-driven.

Do not build global territory simulation, passive-income empire, dozens of capture points, PvP, daily decay, or generic map capture.

Acceptance: leaving is clearly safe; staying is meaningfully tempting; territory feels dog-like; defeat hurts without deleting long-term progress.
