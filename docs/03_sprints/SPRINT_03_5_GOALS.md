# Sprint 03.5 — GOALS
Goal: every walk has an optional short-term reason, and goals can naturally create follow-up intentions.
Scope: 1 primary dog desire/run, up to 2 emergent desires, persistent threads, simple goal chains, discovery state, save/load, lightweight UI. No traditional quest-log dependency.
Scales: immediate (seconds–2m), run (5–15m), multi-run (30–90m), long-term (park ruler).
Rules: express goals from dog perspective; derive them from smells, places, dogs, objects and prior events; avoid generic kill/collect chores; goals may be ignored.
Acceptance: 5+ templates, 3+ follow-up/fork cases, 2+ emergent triggers, 1 multi-run chain, persistence works, and QA can identify a reason to start another walk.
