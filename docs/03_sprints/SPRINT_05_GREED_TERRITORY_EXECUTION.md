# Sprint 05 — GREED / TERRITORY EXECUTION

## Product Question
“I already have enough to go home safely… but there is one more thing I really want.”

## Goal
Turn a completed walk into a voluntary risk decision. Territory is a relationship with a place/rival, not a map-control economy.

## Gate
Engineering starts only after P-04 Brawl Feel Gate passes or is explicitly approved with named changes.

## Vertical Slice
One fixed territory: BIG BANYAN TREE.

explore → collect value → extraction available → notice Banyan temptation → voluntarily continue → scent/rival/mark event → seamless conflict if provoked → extract → bank loot + advance territory relationship.

## P0
SAFE / UNBANKED / PERMANENT value; voluntary extraction; Big Banyan landmark; MARK_TERRITORY; persistent Rival Pair; UNKNOWN/DISCOVERED/CONTESTED/CLAIMING/OWNED; claim consolidation after relevant successful extraction; one ownership reward; Dog Desire integration; consistent defeat rules.

## Non-Goals
No global territory map, passive-income empire, capture rings/flags, daily decay, PvP, new combat architecture or BattleScene.
