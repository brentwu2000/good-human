# GOOD HUMAN! — Design Principles

These principles protect the identity of the game.

1. **The player is the dog.** Never solve a design problem by quietly turning the player into the human.
2. **The dog trains the human.** Dog actions create training tags/progress; the skill tree deepens that growth.
3. **Appearance does not equal combat strength.** A frail-looking person may be terrifyingly strong; a muscular person may be inexperienced.
4. **Human combat is autonomous.** The player configures the human and intervenes only through limited dog actions/QTE.
5. **Every walk is an extraction run.** Search, gain value, become attached to loot, then decide when to leave.
6. **Failure hurts but never ends the save.** Unprotected run loot/equipment can be lost; permanent progression remains.
7. **Fixed neighborhood, changing run content.** Do not procedurally generate the whole city. Randomize loot, encounters, events and extraction conditions.
8. **Comedy emerges from systems.** Dog logic applied to human society should create the joke.
9. **One owner matters.** This is not a human-collection game. The relationship with one random owner is central.
10. **Single-player first.** Architecture should not gratuitously block future multiplayer extraction, but no multiplayer implementation now.
