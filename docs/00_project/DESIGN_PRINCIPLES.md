# GOOD HUMAN! — Design Principles

These principles must survive implementation changes.

1. The player is the dog.
2. The dog trains the human.
3. The owner is not a collectible roster; one owner matters.
4. The owner is random rather than directly selected by the player.
5. Dog actions create meaningful human growth.
6. Human combat is autonomous; the dog intervenes only in limited impactful ways.
7. Appearance does not equal combat strength.
8. Every walk is an extraction run.
9. Failure hurts, but never deletes the save.
10. Fixed neighborhood, changing run content.
11. Comedy should emerge from systems as well as writing.
12. Single-player first; avoid architecture that needlessly blocks future extraction multiplayer, but do not implement multiplayer now.
13. Dog-human attachment matters underneath the absurdity.
