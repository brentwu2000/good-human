# GOOD HUMAN! — 3D Extraction Visuals v0.1

Status: REVIEW
Deliverable: ART-040

The bus stop and north park gate retain their physical environment models. Each exit adds a compact world-space destination marker: four open ground corners, a narrow beacon and a paw sign. Locked exits use muted grey; availability changes the beacon to green through the existing `set_available()` path.

The marker must read from dog height without resembling an arena boundary. Unlock time, interaction radius and extraction behavior remain unchanged.
