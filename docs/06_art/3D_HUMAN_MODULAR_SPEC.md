# GOOD HUMAN! — 3D Human Modular Base v0.1

Status: REVIEW
Deliverable: ART-038

The playable owner and all current opponents use the same proportion-compatible modular base with independently authored hair, top, bottom, accessory and shoe modules. Appearance fields live on `FighterData` but are never derived from combat stats.

Current module library:

- Hair: short, bob, curly, cap, bun
- Tops: overshirt, hoodie, work jacket, tee, cardigan
- Bottoms: straight, cuffed, wide
- Accessories: none, glasses, messenger bag, tote, backpack
- Shoes: independently colored low-top shoes

All six existing humans have distinct combinations. The strongest current opponent deliberately uses an ordinary cardigan, wide trousers and tote bag so silhouette does not become a reliable strength indicator.

Acceptance requires readable variation from the default dog-height camera, stable combat origins, intact fade behavior and no correlation between appearance enum values and stats.
