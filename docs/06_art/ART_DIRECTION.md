# GOOD HUMAN! — Art Direction v0.1

## Target
Modern urban 2D game with a readable 3/4 top-down presentation and a distinctive hand-drawn/cartoon finish.

Avoid:
- generic fantasy RPG look;
- low-detail “free asset pack” appearance for main characters;
- overly childish pet-game presentation;
- inconsistent pixel/vector/painted styles mixed together.

## Priority
1. Dog
2. Human owner
3. Dog-human scale / leash / camera
4. Target gameplay screenshot
5. Neighborhood/park environment
6. UI
7. Props/items/FX

## Characters
Dog and owner are the visual identity of GOOD HUMAN!.

Final dog/human art must reach S-level quality even if an A-level free base is used.

Human system should support modular variation:
Body + Head/Face + Hair + Top + Bottom + Shoes + Accessory.

Human visual design must not communicate true combat power reliably.

## Environment
Free CC0 assets can be used more aggressively for roads, vegetation, benches, bins, fences, buildings and park props, then unified through:
- scale
- palette
- outline
- shading
- signage
- GOOD HUMAN!-specific props

## UI
Dog-perspective visual language:
- dog tags
- leash motifs
- paw/footprint cues
- stickers
- sniff/scent symbols
- photographs
- playful but not preschool-like

## First Visual Target
Create one representative gameplay target showing:
- player dog
- owner on leash
- another dog/human pair
- residential street leading into park
- searchable object
- mobile HUD
- readable dog/human proportions
