# GOOD HUMAN! — 3D Search Props v0.1

Status: REVIEW
Deliverable: ART-039

Searchable objects use distinct dog-height silhouettes instead of a shared cylinder placeholder:

- Street trash: tied dark bag with a small colored scrap
- Mailbox: raised box, curved cap, mail slot and red flag
- Park bush: clustered foliage with a half-hidden paper scrap
- Bench cache: wooden seat with a visible forgotten object
- Gym corner: soft bag, shoulder strap, teal patch and bottle

The props remain presentation-only. Search radius, duration, loot tables, rarity scent, one-time state and cancellation distance are unchanged. Accent color may identify an object family but never loot rarity; rarity remains communicated only by the existing scent system.

Acceptance requires each category to read without its text label at normal chase-camera distance, remain visible at dog height and fade correctly after a one-time search.
