# Sprint 01 Blind QA Brief

You are testing GOOD HUMAN! for the first time.

## What You Know
- You play as a dog.
- This build focuses on going for a walk, searching, carrying items and returning home.
- Use the controls exposed by the game itself.

## Phase A — Explore Blindly
Do not read source code or implementation notes.

Try to:
- leave home;
- understand movement;
- discover things worth interacting with;
- find items;
- understand the difference between normal carried items and protected dog storage;
- discover how to return safely;
- return home;
- go out again.

Do not use debug tools during this phase.

Report:
1. What was immediately understandable?
2. What was confusing?
3. What did you try that did not work?
4. Did you notice extraction becoming available?
5. Did you ever think “I should leave, but I want to search one more thing”?
6. Did protected dog storage feel valuable?
7. Did you want to start another walk?

## Phase B
After the exploratory report is written, run the Golden Path in `docs/03_sprints/SPRINT_01_WALK.md`.

Record pass/fail for every step and file bugs by severity.
