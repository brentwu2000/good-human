# Phase 2 — Vertical Slice Gate

Do not automatically proceed to Sprint 03 just because Sprint 02 is technically complete.

After Sprint 02 QA fixes, play approximately 10 runs across development/QA sessions and review the following.

## Gate Questions

### G1 — Extraction Tension
After finding valuable loot, did continuing the run create real hesitation?

Evidence:
- player voluntarily extracts early sometimes;
- player sometimes takes “one more search” risk.

### G2 — Opponent Curiosity
When seeing another dog/human pair, did the player want to know how strong the human actually was?

### G3 — Autonomous Combat
Does watching the raised human fight feel interesting enough to support the game concept?

Do not require perfect combat yet. Determine whether the concept has potential.

### G4 — Missing Dog Agency
During combat, does the player naturally want to bark, pull the leash, interfere or help?

This is useful evidence, not automatically a failure.
It informs Sprint 04 dog-QTE design.

## Decision

- PROCEED
- PROCEED WITH CHANGES
- REWORK CORE LOOP

Include evidence, not only opinion.
