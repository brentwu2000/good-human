# Sprint 03.5 Blind QA
Use fresh Codex context. Before exploration do not inspect source, goal tables, chain graph or known bugs.
Ask after several walks: Did you know what you wanted to do? Did world events create new intentions? Did completion/failure suggest what to do next? Did goals feel like generic daily chores? Could you ignore them? Did prior walks matter? Did discoveries create curiosity? Why did you want another walk? Did these feel like the dog's desires?
Write exploration findings before reading acceptance criteria.
