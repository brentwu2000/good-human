# Core Experience Gate 02

Run after Sprint 04 QA/fixes.

## Test
Without relying on title/logo/lore, can a player describe the gameplay roughly as:
“I am a dog, I train a human, the human fights for me, and I can run around and interfere.”

## Evidence
- WALK creates reasons to move/explore.
- FIGHT creates risk/curiosity.
- TRAIN makes human growth attributable to dog behavior.
- GOALS create a reason for another walk.
- DOG AGENCY prevents passive combat spectating.
- Selected camera strengthens rather than obscures this identity.

Decision:
PROCEED TO TERRITORY/GREED
PROCEED WITH CHANGES
REWORK CORE EXPERIENCE
