# P-02 Blind QA
Fresh context. Compare prior combat framing and P-02 on identical encounter before implementation details.

Ask:
Did combat feel more tense and like “my human is fighting while I am the dog”?
Could you always find owner?
Did you still feel free?
Did you naturally circle/reposition?
Did camera fight movement?
Were Bark/Pull consequences readable?
Could you notice interactables?
Did crisis/win/loss feel stronger?
Any nausea/disorientation?

Adopt only if relational/tension gains outweigh navigation/camera discomfort.
